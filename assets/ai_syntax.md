# tdx选股药丸 · 选股公式语法规范

> 本文档是该 APP 选股公式的**唯一权威语法规范**，供 AI 将其他软件（通达信、同花顺、大智慧、文华、聚宽、Python 量化等）的公式/策略改写为本 APP 公式时使用。只可使用本文列出的常量、函数与写法；本文未列出的函数一律不得使用，须改写成等价组合。

## 1. 总体结构

- 一行一条语句，语句之间用换行或英文分号 `;` 分隔。
- 每条语句必须是赋值或输出，三种等价形式：
  - `name = 表达式`（Python 风格赋值，推荐）
  - `name := 表达式`（通达信风格赋值，等价于 `=`）
  - `name: 表达式`（通达信风格输出语句）
- **选股信号**：无 `:` 输出语句时，最后一条语句的值即为信号；有 `:` 输出语句时，最后一个输出语句为信号。信号序列中值为 `1`（非 0）的 K 线表示触发选股。
- 变量名：字母开头，可含数字、下划线，大小写不敏感（内部统一转大写，故 `ma` 与 `MA` 相同）。
- 不支持注释（`#`、`//`、`{ }` 都会出现语法错误），不要输出任何注释。
- 不支持跨周期引用（如通达信的 `"MACD.DIF#WEEK"`、引用大盘指数的写法一律不可用），只能基于当前周期给定根数的 K 线计算。

## 2. 数据常量（序列，逐根取值，大小写不敏感）

| 常量 | 含义 | 别名 |
| --- | --- | --- |
| close | 收盘价 | c |
| open | 开盘价 | o |
| high | 最高价 | h |
| low | 最低价 | l |
| volume | 成交量 | v、vol |
| amount | 成交额 | 无 |

除以上常量外，所有标识符必须是本公式前面已赋值的变量，否则报"未定义的变量"。

## 3. 函数（共 22 个，参数个数固定，大小写不敏感）

### 基础函数

| 函数 | 参数 | 说明 |
| --- | --- | --- |
| ma(x, n) | 序列, 整数 | N 日简单移动平均，前 N-1 根为无效值 |
| ema(x, n) | 序列, 整数 | N 日指数移动平均（alpha=2/(N+1)） |
| sma(x, n, m) | 序列, 整数, 整数 | 中国版递推平均：Y = (X*M + Y'(N-M))/N，KDJ 的 K、D 用它 |
| ref(x, n) | 序列, 整数 | 引用 N 根前的值；N 为负数时引用未来（未来函数，慎用） |
| llv(x, n) | 序列, 整数 | 最近 N 根最小值 |
| hhv(x, n) | 序列, 整数 | 最近 N 根最大值 |
| sum(x, n) | 序列, 整数 | 最近 N 根求和 |
| count(cond, n) | 序列, 整数 | 最近 N 根内 cond 非 0 的次数 |
| abs(x) | 序列 | 绝对值 |
| max(a, b) | 序列, 序列 | 逐根取大 |
| min(a, b) | 序列, 序列 | 逐根取小 |
| if(cond, a, b) | 序列, 序列, 序列 | cond 非 0 取 a，否则取 b |
| cross(a, b) | 序列, 序列 | A 上穿 B（本根 A>B 且上根 A<=B），成立为 1 |

### 信号去抖（非未来函数）

| 函数 | 参数 | 说明 |
| --- | --- | --- |
| filter(cond, n) | 序列, 整数 | 信号去抖：条件成立后 n 根内的再次触发置 0，仅保留间隔超过 n 的信号 |

### 未来函数族（拐点靠未来走势确认，信号可能漂移/重绘，选股结果仅供参考）

| 函数 | 参数 | 说明 |
| --- | --- | --- |
| zig(x, n) | 序列, 数字 | 之字转向：价格变动超过 N% 时确认拐点，输出最近已确认拐点价 |
| ziga(x, n) | 序列, 数字 | zig 的绝对量版：变动超过 N 元时转向 |
| peak(x, n, m) | 序列, 数字, 整数 | 前 m 个 zig 波峰值（m=1 为最近波峰，确认前为无效值） |
| peakbars(x, n, m) | 序列, 数字, 整数 | 前 m 个波峰到当前的周期数 |
| trough(x, n, m) | 序列, 数字, 整数 | 前 m 个 zig 波谷值 |
| troughbars(x, n, m) | 序列, 数字, 整数 | 前 m 个波谷到当前的周期数 |
| backset(cond, n) | 序列, 整数 | cond 非 0 时将当前到前 n-1 根置 1 |
| refx(x, n) | 序列, 整数 | 引用未来第 n 根的值（等价 ref(x, -n)） |

未来函数名单：zig、ziga、peak、peakbars、trough、troughbars、backset、refx，以及 ref(x, -n) 负偏移。含未来函数的公式 APP 会显示警示，属合法用法但不要滥用。

## 4. 运算符

- 算术：`+ - * /`（除零结果为无效值）
- 比较：`> < >= <= == !=`（也可用 `=` 表示等于，`<>` 表示不等于），结果为 1 或 0
- 逻辑：`and or not`（大小写不敏感），也可用 `&` 和 `|`
- 括号：`( )`，可任意嵌套
- 数字：支持小数与科学计数法；函数的第 2/3 个参数（周期数）必须是数字常量

## 5. 常见指标的等价写法（MACD/KDJ 没有内置函数，按下法手写）

MACD（12,26,9）：
```
dif = ema(close, 12) - ema(close, 26)
dea = ema(dif, 9)
macd = 2 * (dif - dea)
```

KDJ（9,3,3 即 sma 的 m=1）：
```
rsv = (close - llv(low, 9)) / (hhv(high, 9) - llv(low, 9)) * 100
k = sma(rsv, 3, 1)
d = sma(k, 3, 1)
j = 3 * k - 2 * d
```

均线多头： `xg = ma(close, 5) > ma(close, 10) and ma(close, 10) > ma(close, 20)`

放量上涨： `xg = close > ref(close, 1) and volume > ma(volume, 5) * 2`

## 6. 转换规则（AI 执行其他软件公式改写时遵循）

1. 源公式中的赋值（通达信 `:=`、同花顺 `:=`、Python `=`）一律改写成 `name = 表达式`。
2. 源公式中的输出语句（通达信 `NAME:表达式`）保留 `:` 形式或并入最后一条信号语句，二者取其一，不要同时使用。
3. 源公式用到的函数若在本文第 3 节不存在，必须改写成第 3 节函数的等价组合；无法等价时，用最接近的近似并在"转换说明"中告知用户。
4. 绘图语句（STICKLINE、DRAWICON、DRAWTEXT、PARTLINE 等）、引用其他周期/其他股票的语句一律删除，不参与选股信号；只保留选股条件逻辑。
5. 参数默认值（如 N=9、M1=3）保持源公式取值，不要擅自修改。
6. 布尔信号最终须落到"最后一条语句为 1 表示选中"的形式。
7. 输出代码中不得出现本文未定义的函数、常量、注释或跨周期引用，否则编译报错。
